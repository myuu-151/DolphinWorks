GDB

Pause the game on the console, set breakpoints, step through code, catch crashes. The game must be running and built with libogc's debug stub (DEBUG_Init).

It opens in its own window, connected to the Gecko (the console lets go of the port). By hand:

powerpc-eabi-gdb.exe game.elf
(gdb) target remote \\.\COM3

The USB Gecko goes in memory card slot A. In Dolphin, DolphinWorks' profiles emulate one in slot B.

Commands
continue
run the game (c)
Ctrl+C
pause it, wherever it is
bt
where it stopped: the calls that led there
break player_update
stop at a function (or break file.cpp:120)
print hp
a variable's value (p/x hp in hex)
printf "%d\n", hp
formatted, as in C
info locals
this function's variables
next / step
one line; step goes into calls
finish
run to the end of this function
set var hp = 999
change a variable
x/16x 0x80001234
16 words of memory
delete
remove all breakpoints
quit
leave GDB
